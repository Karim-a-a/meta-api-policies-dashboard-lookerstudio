Description du service :

Notre application collecte et visualise des données publicitaires provenant de Meta (Facebook, Instagram) via l'API Marketing de Meta, afin de fournir des tableaux de bord analytiques à nos clients annonceurs et équipes internes.

2. DONNÉES COLLECTÉES

2.1 Types de données

Nous collectons exclusivement des données publicitaires agrégées via l'API Marketing de Meta :

  • Métriques de performance : impressions, clics, portée, fréquence
  • Données financières : dépenses publicitaires, coût par résultat (CPM, CPC, CPA)
  • Données de performance des campagnes : taux de conversion, résultats par objectif
  • Données techniques : identifiants de campagnes, ensembles de publicités, créations publicitaires

2.2 Données NON collectées

  • ❌ Données personnelles identifiables
  • ❌ Données démographiques individuelles
  • ❌ Informations sur les audiences au niveau individuel
  • ❌ Données de profils utilisateurs Facebook/Instagram

3. BASE LÉGALE DU TRAITEMENT (RGPD)

Le traitement de données repose sur :

  • Intérêt légitime (Art. 6.1.f RGPD) : fourniture de services d'analyse publicitaire à nos clients
  • Exécution contractuelle (Art. 6.1.b RGPD) : obligations contractuelles envers nos clients annonceurs
  • Consentement : via l'authentification OAuth Meta, les utilisateurs autorisent l'accès à leurs données publicitaires

4. UTILISATION DES DONNÉES

Les données collectées sont utilisées pour :

  • ✅ Visualisation : création de tableaux de bord Looker Studio
  • ✅ Reporting client : rapports de performance pour nos clients annonceurs
  • ✅ Analyses internes : évaluation et optimisation des stratégies publicitaires
  • ✅ Optimisation indirecte : insights pour l'amélioration des campagnes

Nous n'utilisons PAS ces données pour :

  • ❌ Revente à des tiers
  • ❌ Profilage individuel
  • ❌ Publicité ciblée hors du cadre contractuel

5. PARTAGE DES DONNÉES

5.1 Destinataires

Les données sont partagées avec :

  • Google Looker Studio : plateforme de visualisation (sous-traitant)
  • Nos clients annonceurs : propriétaires des comptes publicitaires Meta
  • Équipes internes KINESSO : analystes, consultants autorisés

5.2 Transferts internationaux

  • Google Looker Studio peut impliquer des transferts vers les États-Unis
  • Ces transferts sont encadrés par les Clauses Contractuelles Types de la Commission Européenne

5.3 Aucune revente

Nous ne vendons, ne louons ni n'échangeons vos données avec des tiers à des fins commerciales.

6. SÉCURITÉ DES DONNÉES

Mesures de sécurité mises en œuvre :

  • 🔒 Authentification OAuth 2.0 : accès sécurisé aux comptes Meta
  • 🔒 Chiffrement des communications : HTTPS/TLS pour tous les échanges API
  • 🔒 Contrôle d'accès : limitation des accès aux personnes autorisées
  • 🔒 Conformité Meta : respect des exigences de sécurité de Meta Platform Terms

7. DURÉE DE CONSERVATION

  • Données actives : conservées conformément aux limites de l'API Meta (maximum 37 mois de données historiques accessibles)
  • Suppression : les données peuvent être supprimées à la demande du client annonceur propriétaire du compte Meta
  • Fin de relation contractuelle : suppression dans les 30 jours suivant la résiliation du contrat

8. VOS DROITS (RGPD)
